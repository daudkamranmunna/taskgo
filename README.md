# TaskGo - Study Streak & Focus Tracker

TaskGo helps students build consistent study habits. It rewards consistency (daily streaks), not just total hours, and connects studying to tasks and deadlines.

This is a college semester project, built step by step.

## Planned features
- Register / login
- Study timer (stopwatch, 25/45/60 min, custom countdown) with a ringing alarm
- Tasks with priorities and deadline countdowns, linked to the timer
- Study streaks and daily goal progress ring
- Weekly progress report and 28-day streak calendar
- Achievement badges
- Study history and motivational quotes

## Tech stack
- Mobile app: React Native + Expo (Expo Router, JavaScript)
- Backend: Node.js + Express
- Database and login: Supabase (Postgres + Auth)
- Hosting: Render
