## Files generated by the Expo starter (not written by us, leave them alone)
- mobile/.gitignore, package-lock.json, tsconfig.json, expo-env.d.ts, AGENTS.md, README.md, LICENSE
- mobile/assets/ (icons and splash images; replaced in Step 14)
- mobile/.vscode/, mobile/.expo/ (editor and Expo settings)
- tsconfig.json and expo-env.d.ts are TypeScript leftovers. All our own code is plain JavaScript. Tidying these up is optional (Step 14).

## Notes
- The starter put its screens in mobile/src/app. We moved them to mobile/app, so screens live in mobile/app and our own code lives in mobile/src.
- Built so far: backend (all files), mobile/app/index.js, mobile/app/_layout.js (plain Stack, no login check yet), the 5 placeholder tab screens, theme.js, config.js, and the components ScreenContainer, Card, Button, Input, LoadingView, EmptyState.
